# Dog CEO Generator

Aceasta este aplicația pentru Tema 2. Utilizează **Dog CEO API** pentru a genera imagini aleatorii cu câini și extrage automat rasa acestora pentru a o afișa într-un tabel de detalii.

## Funcționalități
- **Fetch API:** Preluare asincronă a imaginilor.
- **Data Parsing:** Extragerea numelui rasei direct din URL-ul imaginii.
- **Error Handling:** Gestionarea erorilor de rețea cu blocuri try/catch.
- **Logging:** Sistem de logare în consolă pentru depanare (F12).

## Cum se folosește
1. Deschide `index.html` în browser.
2. Apasă butonul "Generează Câine Nou".
3. Vezi imaginea și detaliile despre rasă în tabel.
